# GTI Widget Vendor Example

**NOTE: This project is for Proof of Concept (POC) purposes only. It is not intended for production use.**

## Description

`gti_widget_vendor_example` provides a reference implementation for third-party vendors looking to embed a Google Threat Intelligence (GTI) widget within their own platforms or dashboards. It demonstrates the seamless integration of GTI capabilities into external environments.

## Important
Do not include sensitive keys or credentials in this repository. Ensure API keys are provided securely by the end user or via secure environment configuration.
